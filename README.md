# Release

Release 是 VeriRelay 的发布流水线。每个发布都附带一条发布证据链，从启动度量连到每个组件的源码 commit，可离线复核。

Release is the release pipeline for VeriRelay. Every release ships a Release Evidence Chain from the Launch Measurement to the source commit of each component, verifiable offline.
